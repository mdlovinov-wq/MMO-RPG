# MMO-RPG

Лабораторная работа по объектно-ориентированному программированию.

# Выбор паттерна

Для создания юнитов был выбран паттерн "Фабричный метод" вместо "Абстрактной фабрики", так как абстрактная фабрика избыточна.
Все конкретные виды юнитов наследуются от класса Unit, а их создание можно инкапсулировать в отдельных фабриках.
Задача не трубет создания целых семейств, так как в нём всего 6 различных видов юнитов.
